# 🧠 Momentum — Semester 7 Focus & Memory Hub

> An ADHD-friendly, high-focus exam revision and curriculum tracking application built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Firebase**.

## ✨ Features

- 📚 **AI Curriculum Roadmap** — Karpathy, Krish Naik, and more broken into structured lectures
- 📜 **Auto Transcript** — fetch YouTube transcripts per lecture with precise timestamp slicing
- 🚀 **ChatGPT Export** — one-click export of transcript + ADHD-friendly study prompt to ChatGPT
- ✅ **Focus Tasks** — track daily tasks with Firestore persistence
- 🎯 **WOOP Goals** — structured goal setting (Wish, Outcome, Obstacle, Plan)
- 🧩 **Session Recall** — spaced repetition recall practice after study sessions
- 📊 **Statistics** — track your study streaks and progress

## 🛠 Tech Stack

- React 19 + Vite
- TypeScript
- Tailwind CSS
- Firebase (Auth + Firestore)
- Express.js backend (transcript API)

## 🚀 Getting Started

```bash
npm install
npm run dev
```
